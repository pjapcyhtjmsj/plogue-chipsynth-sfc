## Overview

chipsynth SFC reproduces the Sony SPC700 DSP at cycle level, emulating the SNES sample-based synthesis including its ADSR, Gaussian interpolation, echo feedback, and seven-band peak EQ filters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plogue chipsynth SFC** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **SPC700 Emulation** | Cycle-accurate DSP simulation matching hardware timing and quirks |
| **Gaussian Interpolation** | Authentic SNES 8-sample Gaussian interpolation filter |
| **Echo Engine** | Hardware-accurate echo feedback delay with FIR filter coefficients |
| **BRR Sample Import** | Load original SNES BRR-encoded samples from SPC dump files |
